What Is ClearEdge3D EdgeWise?

ClearEdge3D EdgeWise is advanced as-built modelling software that accelerates the conversion of registered LiDAR point clouds into intelligent BIM geometry.

Automated Feature
Extraction

Automatically extracts pipes, structures, ducts, walls, conduits and cable trays from LiDAR point clouds.

Built-In Model QA/QC

SmartSheet QA/QC validates point-cloud coverage, specifications, element dimensions and modelling accuracy for confident delivery.

Intelligent Point-
Cloud Exports

Export Remainder Clouds and Smart Points for visualisation, downstream modelling, analysis and Digital Twin workflows.

Direct Software Integration

Export intelligent models directly into Autodesk Revit, Autodesk Plant 3D and AVEVA E3D Design for seamless engineering workflows.

From LiDAR Capture to Intelligent As Built BIM

1 Capture with LiDAR

Capture accurate existing-condition data using a terrestrial or mobile LiDAR scanner.

2 Register the Point Cloud

Align and register the individual scan positions into one coordinated point-cloud dataset.

3 Import into EdgeWise

Load the clean, registered point cloud into ClearEdge3D EdgeWise.

4 Extract and Verify

Extract pipes, structures, ducts, walls, conduits and cable trays and verify the fitted geometry.

5 Export Intelligent Models

Transfer intelligent models into Revit, Plant 3D, AVEVA E3D Design and compatible workflows.
